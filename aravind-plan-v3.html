Non-Negotiable Rules
These don't bend. Ever.
01
No applications in Month 1–2
Your profile isn't ready. Applying now gets you junior interviews, not $130K ones. You only get one shot per company — don't waste it with a half-built profile.
02
Precision over volume — always
5–10 targeted applications beat 50 generic ones. You have ~150 real target roles. Know each company. Tailor the resume. Reach out to the engineering manager directly.
03
Learn TypeScript by building Doop
No passive watching. Every GitHub push is portfolio evidence. A watched course with no code is entertainment, not preparation. Build or it didn't happen.
04
No junior roles. No internships.
You shipped a production app to 10,000+ users. Applying junior signals you don't believe in your own value. Mid-level minimum ($100K+) if month 6 has zero offers.
05
Animations serve features — 80/20 split
One Reanimated 3 animation per Doop feature. 80% core stack, 20% animations. Passion is the edge — not the distraction. No offer = no animation sprints.
06
Run V4 for 30 days before changing anything
Around day 10–12 Doop feels more exciting than applications. A new idea appears. Name the pattern and return to the plan. The plan needs follow-through, not improvements.
⚠️
Watch For These
Common traps — name them before they happen
🚫
Don't learn AI before TypeScript. The sequence is TypeScript → New Architecture → AI integration. Skipping ahead means building on sand. AI layer comes in month 5–6, not month 1.
🚫
Don't apply to React web roles. Your production mobile story is worth $150K in RN. That same story in React web reads as "mobile dev trying web" — immediate salary discount.
🚫
Don't go deep on backend. You already clear the bar — FastAPI, REST, auth, real-time sync. tRPC basics in month 5–6, two weeks only. Backend depth is a 12-month detour.
